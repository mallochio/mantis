# 2026-08-01 Conductor pipeline smoke (135M proxy)

**Status:** pipeline-only smoke, not a real-3B acceptance run.

**Pipeline-only smoke.** It did not load, train, or validate the 3B OpenFugu Conductor. Not valid for runtime.

## Why this exists
The real `di-zhang-fdu/openfugu-conductor-3b` checkpoint is a Llama-3.2-3B model
that cannot fit in this CPU-only sandbox, and this AWS account has no GPU quota
available for SkyPilot. To exercise the new `scripts/retrain_conductor.py` wrapper,
prompt template, DAG parser, and GRPO reward pipeline, a 135M parameter
instruction-tuned proxy (`HuggingFaceTB/SmolLM2-135M-Instruct`) was used.

## Run details
- Base model: `HuggingFaceTB/SmolLM2-135M-Instruct` (proxy, not the real checkpoint)
- Device: `cpu`
- GPU: none
- Steps: 20
- Task limit: 8
- Generations per step: 2
- Per-device batch: 2
- Dataset: `s3://external-datasets-archive/terminal-bench-2.1/`
- Pool: 7 requested frontier models via OpenRouter ids with reasoning effort tags
- Output: `outputs/conductor_retrain/20260801-135M-smoke/`
- `valid_for_runtime`: **false**
- `real_checkpoint_loaded`: **false**

## Result
The pipeline completed end-to-end and produced:
- `outputs/conductor_retrain/20260801-135M-smoke/pool.json`
- `outputs/conductor_retrain/20260801-135M-smoke/dataset.json`
- `outputs/conductor_retrain/20260801-135M-smoke/metrics.jsonl`
- `outputs/conductor_retrain/20260801-135M-smoke/checkpoint/`
- `outputs/conductor_retrain/20260801-135M-smoke/manifest.json`

`metrics.jsonl` shows non-zero, fluctuating `rewards/conductor_format_reward/mean`
(0.0, 0.5, 1.0 across steps), confirming the prompt template and DAG parser are
working. The action and outcome rewards followed the format reward. Because a
proxy model was used, the checkpoint is not suitable for deployment.
